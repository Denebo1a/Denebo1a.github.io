# 心理建设
为什么要进行女装活动呢？这个问题的答案千人千面。

这种个体差异性，同时也体现在我们内心的困扰上——那些因为有了女装想法，便开始簇生的各种烦恼，也是因人而异，难以一言蔽之。

在物理层面上，开始女装的门槛并不高。然而，随着女装活动的深入，我们不可避免地会触碰到到自我认同、社会规范与外界评价的敏感边界，种种始料未及的糟糕情绪也许会接踵而至。

如果这确实符合您当下的情状，首先需要认识到的是，虽然大家面临的问题各不相同，但您绝对不是孑然一身，这几乎是所有伪娘的必经之路。

在这一部分，抱着自我总结检讨的心态，笔者试图提取出一些较为普遍的，与女装活动伴生的心理困扰，并给出自己的疏解方案，希望能帮助到各位读者朋友。

在开始之前，笔者想引用一段话，希望可以鼓励到，或许正在经历困境的朋友：

> 女装之道是Try and Error。绝对没有什么终点或是目的地，失败的同时会发现新的道路，再失败又会有新的发现，就是这样周而复始的重复。<br>
> 不过，可以说这一点正是女装的乐趣所在。
> <p align="right">——《好想做个女孩子》（《オンナノコになりたい》· 三葉[著] · 一千零一夜COS剧社[译]）</p>

## 外貌/身材焦虑

这应该是每个追求理想女体化表达的伪娘都难以避免的心魔。这个困扰并非是阶段性的，它极有可能长久地存续。
