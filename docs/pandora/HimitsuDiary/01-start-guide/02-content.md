# 阅读指南

在这一部分，您将了解到：

## 信息来源与可信度
对于信息的**源头**和**可信度**，笔者会大致按照以下的样式标注：
- **自身经验**：没有任何引用标记/其他标注的正文内容默认为笔者的自身经验
- **来自互联网/书籍**：带有引用标记的正文内容
- **可信度尚未得到验证**：带有黄色高亮标注的正文内容
- **AI生成内容**：一般为一些说明图片，带有“此内容为AIGC”的标注

## 心理建设
与您在生活中的其他心理困扰不同，与女装相关的负面情绪，往往难以通过常规的途径来倾诉与消解。或许是难以启齿，或许是难觅知音......以致这份情绪不断淤积，甚至上升到症候的程度。

因此，在开始介绍其他外在的知识与技术之前，深入探讨内部心理建设是相当有必要的。
