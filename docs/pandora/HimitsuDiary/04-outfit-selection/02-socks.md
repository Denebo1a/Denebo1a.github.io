# 袜类

在现代男性的日常穿搭中，袜子的存在感一般并不很强。16世纪的欧洲贵族老爷们在疯狂迷恋凸显腿部线条的丝质长筒袜时，想必不会料到如今的光景。

而另一边，在女孩子们的时尚表达中，样式种类繁复多变的女袜已经成为不可或缺的存在，完全可以作为一种单独的服饰品类展开介绍了。

袜子能够成为一层外置的美丽皮肤；袜子能够修饰、勾勒、升华脚部/腿部的曲线；袜子还有许多难以解释却又直击人心的效果......

### 按纤维粗细来分

如果谈到**丝袜**这样由化学纤维长丝编织的袜子，**D数**就是一个绕不开的话题了。
::: tip 名词定义
丹尼尔数（Denier，简称D数），用于衡量纤维粗细的单位。<br>
每9000米长的纤维重多少克，就称为多少D。
:::
一个比较朴素简单的理解是这样的：

**D数越大，纤维越粗，袜子越厚实、越耐穿、越不透明；D数越小，纤维越细，袜子越轻薄、越透明。**
