# 在这里可以看到哪些内容呢？

正如前面所说，这里写的都是一些很私人化的东西，而且几乎没有什么营养（大实话）。

## 女装日记
在这个模块会发布一些男性穿女装相关的内容，等等，这好像是一句废话（笑）。

这是个对大众而言，可以说有点糟糕而尴尬的领域，如果吓到了正在浏览网页的您，请允许我先行致歉。

> [!CAUTION]
> 注意：若您对伪娘文化不是很感冒，该模块部分内容可能会令您感到生理不适。

言归正传，「女装日记」除开作为一个异装癖的树洞使用，还有一些其他的野心。

如您所见，现在所用的 Vitepress 默认主题真的很适合写技术文档。我希望以自己微薄的力量，开始系统性地整理一些女装方面的经验与方法论。若是能给路过的同好提供一些帮助，那就再好不过了。
