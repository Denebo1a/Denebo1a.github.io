# 示例文本

林家里的镜子碎了。

昨天喝得有点多……他喃喃道。

耷拉着脑袋挤进逼仄的洗手间，拖鞋下传来坚硬的触感。

林拨开过分长的刘海，这才看见地上的狼藉。

散落的碎片自不必说，还有一块鞋垫大小的残块岌岌地留在墙上，连带着周围黄浊固化的胶水，一副惨不忍睹的景象。

“哗哗……”林将碎渣一股脑儿扫进畚斗里，他冷静得有些迟钝，半晌才一抓脑袋，完全理解了事态。

嘛……反正不是马桶碎了，事到如今，又有什么不能接受的呢。

推开脑中似曾相识的焦躁感，自暴自弃般地撞向卧室的门。三叠半大的起居室不过几步，他却一刻不想逗留——现在，这栋居所唯一的窗户正在那里吐出苍白的阳光，活像监狱里的强光探照灯。

挤开那扇小小的门，空调的冷气裹挟呛鼻的酒精味扑面而来，林猛地一颤，顺势向后倒去，用体重关上了门。地上的易拉罐们挨了一脚，不满地喧闹着，然而终究是无法撼动它们主人那麻痹的神经。

像只蛞蝓似的，林连滚带爬地蠕动到床垫上，要睡到什么时候呢。

不过，还没等到自己的回答，林便昏昏地睡过去了，就像在这蜗牛壳般的房间中曾度过的每一天一样。
