## 为什么 JS 需要原型与原型链

在Java/C#等具有强面向对象特性的语言中，**继承**是一个很基础的概念（面向对象三大特征之一）。继承允许我们在类与类之间设计父子关系，让子类继承父类的属性方法等资产，同时追加自己的新实现，极大提高代码的复用性。

JavaScript为什么要引入原型和原型链呢？从某种意义上讲，就是为了实现类似**继承**的特性，如果不同的对象实例可以共享一套属性与方法，代码的复用性和内存占用都会得到很大优化。
